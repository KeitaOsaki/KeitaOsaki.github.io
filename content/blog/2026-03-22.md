## Cloudflare Analyticsとは

Cloudflare Analyticsは、Cloudflareが提供するアクセス解析サービスです。

特徴としては以下があります。

- **無料で利用可能**（無料プランでも使える）
- JavaScriptのビーコンスクリプトを1行埋め込むだけで導入できる

## 導入方法

### 1. サイトの追加

ダッシュボードから「Web 分析」を選択し、以下の画面の「サイトを追加する」を選択します。

![Cloudflare Web Analytics サイト追加画面](/images/blog/cloudflare-2.png)

### 2. サイトを登録してスクリプトを取得

「サイトを追加」ボタンから該当サイトのホスト名を登録すると、以下のようなビーコンスクリプトが発行されます。

```html
<!-- Cloudflare Web Analytics --><script defer src='https://static.cloudflareinsights.com/beacon.min.js' data-cf-beacon='{"token": "YOUR_TOKEN_HERE"}'></script><!-- End Cloudflare Web Analytics -->
```

`YOUR_TOKEN_HERE` の部分には自分のトークンが入ります。このスクリプトを計測したいページの `</body>` タグの直前に埋め込みます。

### 3. アクセス数の確認

設定後にはしばらくしたらアクセス数を確認できるようになります。
アクセスしないと「データがありません」のような表示が出るのですぐ確認したい場合は自分でアクセス数稼ぐといいかもです。
